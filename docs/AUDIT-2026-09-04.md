## Stage two: the four criteria

### Technological implementation

- Three-layer design with a hard gate: deterministic triggers with character
  offsets → Agent Search retrieval filtered in code by jurisdiction and trigger
  class → ADK agent that must call the safety filter as a tool before answering.
  No clause, no flag. Post-hoc filter still enforced (`adk_app.apply_output_filter`).
- Document-level grounding: the missing-signpost note is retrieved and explained
  like any scene, proposing an end card rather than rewriting a scene.
- Per-scene retrieval and explanation run concurrently; the guidance case
  measured 26.9 s locally against 55.4 s sequential.
- Public API with stateless HMAC keys signed by a Secret Manager secret,
  per-caller sliding-window limits, one error envelope with a `fix` on every
  error, `meta.gate` on every review, Markdown reports rendered from the same
  payload.
- Replit adapters with honest fallbacks: Auth headers trusted only on Replit,
  Database (Postgres → key-value → local file), App Storage export, Scheduled
  re-check script that records metadata only.
- Offline suite: 46 tests, Ruff clean; the deterministic benchmark is served
  live from `/v1/eval/latest` (48 cases, precision 1.0, recall 1.0, false-flag
  rate 0.0 on the shipped engineering set; failures would be listed).

### Design

- Four pages sharing one shell: Review, Demo library, Developers, Stack. The
  sponsor-stack ribbon and the crisis footer are on every page; the footer is
  static HTML so it exists before any script runs.
- Light by default, opt-in dark, Plain/Technical register on every page,
  keyboard focus visible, no horizontal overflow at 1280 and 390 px (Playwright
  check, 2026-09-04).
- Six presets that state their expectation before you run them; bring your own
  in Fountain, text, Markdown, or Final Draft `.fdx` parsed in the browser.
- Results: annotated screenplay page, publisher-attributed source cards with
  jurisdiction and version, ADK alternative with model, filter, and self-check
  chips, decision controls with a reason field, downloads, explicit export.

### Potential impact

- Specific audience with a real access gap (independent and student
  screenwriters without a standards consultant), routed toward human expertise
  where warranted. Claims are bounded: no clinical, compliance, certification,
  or safety claim anywhere in the product or docs.
- **Still open:** the blinded ten-fragment pack in `evaluation/` needs a
  qualified independent reviewer. The tool reports this as `pending` in
  `/v1/eval/latest` rather than implying validation.

### Quality of the idea

- Non-obvious use of the sponsor tools: Agent Search as the only permitted
  source of guidance text; the ADK agent forced through the same filter the API
  applies; Replit Database used to keep decisions without keeping scripts; a
  Replit Scheduled Deployment that tells a writer when the corpus changed under
  a saved decision.
- The two-sample contrast (a concerning draft and a conforming one on the same
  subject) answers "is this a keyword filter" and "is this censorship" in one
  view.
