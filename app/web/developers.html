Integrate the pre-review. Mint a key, run it live, ship it.

Any writing tool, script-coverage service, or production workflow can call the same review this site uses. There is no account: press the button, get a key, and run a live review from this page. Anonymous calls work too, at lower limits.

Keys are stateless HMAC tokens signed with a secret held in Google Secret Manager, so verification is a signature check with no key store. Every response carries data.disclaimer as a required field and meta.gate with the thresholds that were evaluated. Errors use one envelope: { ok:false, error:{ code, message, fix, docs } }.

Returned once, never stored. Expires after 90 days. Cannot be revoked individually; mint one per integration.

Runs the real pipeline with your key: deterministic triggers, Google Agent Search retrieval, the GuidanceContextReviewer on Vertex AI Agent Engine (or in-process ADK, recorded in meta.agent_runtime), and Model Armor on the answer. Nothing is cached.

Call it from your code

Python

import requests

BASE = ""
key = requests.post(f"{BASE}/v1/keys").json()["data"]["api_key"]
r = requests.post(
    f"{BASE}/v1/review",
    headers={"Authorization": f"Bearer {key}"},
    json={"screenplay": open("draft.fountain").read(), "region": "US"},
)
review = r.json()
print(review["meta"]["gate"])            # which thresholds passed and failed
for note in review["data"]["grounded_flags"]:
    for clause in note["clauses"]:
        print(note["heading"], clause["publisher"], clause["source_url"])
print(review["data"]["disclaimer"])      # required field on every response

JavaScript

const BASE = "";
const { data: { api_key } } = await (await fetch(`${BASE}/v1/keys`, { method: "POST" })).json();
const res = await fetch(`${BASE}/v1/review?format=markdown`, {
  method: "POST",
  headers: { "content-type": "application/json", "x-api-key": api_key },
  body: JSON.stringify({ preset_id: "responsible-depiction", region: "US" }),
});
console.log(await res.text()); // a Markdown report, disclaimer first

Full OpenAPI: /docs · /openapi.json. Limits are per minute per caller. Anonymous callers keep working when keys are unavailable. Retention: nothing is stored by default; exports and decisions are explicit. Logged per review: request id, caller tier, counts, model, latency. Never logged: screenplay text, prompts, generated prose.

Error envelope

{
  "ok": false,
  "error": { "code": "rate_limited",
             "message": "review allows 6 requests per minute for this caller.",
             "fix": "Wait and retry, or POST /v1/keys for a key with 5x this limit.",
             "docs": "/docs" },
  "meta": { "request_id": "req_…" }
}

Codes are stable strings: validation_error, invalid_api_key, rate_limited, grounding_failed, agent_review_failed, sign_in_required, api_keys_unavailable. Failures fail closed: no note is ever fabricated from model memory.
