Architecture

Three layers prevent “a prompt with a UI.”

01

Auditable triggers

Pure code shows the exact phrase and rule that produced a candidate. It cannot issue a guidance flag.

02

Retrieved clauses

Google Agent Search returns a versioned source URL. Gemini can explain only what was retrieved.

03

Writer control

Accept, dismiss, or request expert review. Dismissal leaves the reasoning visible. No overall score exists.

Approved corpus
