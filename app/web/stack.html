Track requirements

What the Replit track checks, and where this project stands.

Built with Replit Agent

Mandatory. The owner runs the prompt in replit.md in an authenticated workspace; Agent's transcript and commit become the evidence. The Replit Agent card above stays amber until that record exists, on purpose.

Deployed on replit.app

Mandatory. .replit declares an Autoscale deployment of this same app. Until the public URL exists, the Cloud Run URL is the Google agent backend and a functional fallback, never a substitute for the requirement.

Google Cloud at runtime

Gemini on Vertex AI through Google ADK, the same agent on Vertex AI Agent Engine, Google Agent Search for retrieval, Model Armor on the agent's answer, Cloud Run for hosting, Secret Manager for the signing secret, Cloud Build for CI, Cloud Logging for content-free traces. All imported and called in code, not named in a README.

Only Google AI

No other model, agent framework, or AI API is used at runtime. The deterministic layer is plain code; the safety filter is a regular expression, not a model.
