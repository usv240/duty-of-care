Demo library

Six self-authored drafts. Read them, download them, run them.

Every preset is original fiction written for this project and released under CC0, because the contest forbids using anyone else's screenplay. Each one says in advance what the tool should notice, so you can check the result against the expectation instead of taking a demo on trust.

Presets are served from GET /v1/presets with an expected trigger-class set per file. Downloads come from GET /v1/presets/{id}/download?format=fountain|txt|json. Running a preset performs a live review through Agent Search and the ADK reviewer; nothing is pre-computed.

Your draft never leaves your browser until you press Review.

Formats

Paste plain text or Fountain, or upload a Final Draft .fdx; it is converted to text in the browser. Scene headings beginning INT., EXT., or I/E. become the units of review.

What you get back

An annotated page with each triggering phrase underlined, the exact clause and source link for every note, one alternative from the Google ADK reviewer, and downloads in JSON or Markdown. Nothing is stored unless you press Export.
